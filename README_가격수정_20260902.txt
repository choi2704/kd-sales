KD SALES ERP 가격 수정 최종본

1. GitHub choi2704/kd-sales 저장소의 기존 파일을 모두 삭제합니다.
2. 이 ZIP을 압축 해제합니다.
3. 압축을 푼 안쪽 파일/폴더 전체를 저장소 최상위에 업로드합니다.
4. Commit changes 후 GitHub Pages를 새로고침합니다.
5. 브라우저에서 Ctrl+F5로 강력 새로고침하세요.

이번 버전은 렉산/알루미늄 가격을 index.html 안에도 내장했습니다.
따라서 data 폴더 캐시나 이전 JSON이 남아 있어도 새 가격으로 계산합니다.

알루미늄: mm 직접입력, 최소 500mm, 10mm 미만 단위는 다음 cm 옵션으로 올림 적용
예) 1234mm -> 124cm 옵션가 적용
렉산: 2026-09-02 새 2T/3T 가격표 적용
