강동자바라 온라인팀 견적기 — 차양 VAT 10% 별도 계산 (v1.5)

- 차양 견적기만 변경: 공급가액 + 부가세 10% = 최종금액(부가세 포함)
- 물받이 없음: 가로 × (세로+200) ÷ 90,000 유지
- 물받이 있음: 가로 × (세로+300) ÷ 90,000 유지
- 옆막이 선택 시 차양 1개당 20,000원 추가 유지 (부가세 계산 대상에 포함)
- 부가세는 전체 공급가액의 10%를 원 단위 반올림해 계산
- 계산 결과, 견적 목록, 복사한 내역, 인쇄/PDF 모두 합계 표시
- 온라인팀 나머지 제품의 기존 부가세 포함 계산 방식은 그대로 유지
- 기존 저장된 차양 견적의 공급가액과 계산식은 유지하고 VAT만 화면에 별도 표시
