강동자바라 온라인팀 견적기 차양 계산 변경 (2026-10-20)

1. 물받이 없음: 가로(mm) × (세로(mm) + 200) ÷ 90,000
2. 물받이 있음: 기존과 동일하게 가로(mm) × (세로(mm) + 300) ÷ 90,000
3. 옆막이 있음 체크: 차양 1개당 20,000원 추가 (수량 × 20,000원)
4. 기본 평수는 1평 단위 올림, 평당 가격표, 기타 온라인팀 견적기 기능 유지.
5. 이미 저장되어 있던 견적은 기존 계산식(+100mm)을 그대로 유지해 금액이 임의로 바뀌지 않음.
   저장된 견적을 수정해 다시 저장하면 새 계산식(+200mm) 기준으로 계산됩니다.
6. 기존 GitHub Pages 저장소에 ZIP 압축을 풀고 모든 파일을 덮어쓴 뒤 commit 하세요.

새 예시: 물받이 없음, 가로 1,200mm × 세로 1,000mm = 16평(ceil)이며,
선택한 평당 가격 × 16평 + (옆막이 선택 시 20,000원)으로 1개 금액을 계산합니다.
