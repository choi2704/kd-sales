## V3.1 알루미늄 방범창 입력방식 변경
- 소비자용 스마트스토어 가로·세로 옵션을 드롭다운에서 숫자 직접 입력으로 변경
- 입력 단위: cm
- 허용 범위: 60~300cm
- 1cm 단위 정수만 허용
- 올림·내림 없이 입력값과 정확히 일치하는 옵션 추가금 적용
- 예: 123 입력 → 123cm 옵션가격 적용
- 범위 초과 또는 소수점 입력 시 견적목록 추가 차단


## V3.2 온라인 견적서 부가세 포함 처리
- 온라인팀 판매가격은 스마트스토어 기준 부가세 포함 금액으로 처리합니다.
- 견적 합계에 부가세를 다시 더하지 않습니다.
- 공급가액과 부가세는 최종 결제금액에서 역산해 표시합니다.


- SUS304 방범창 가로·세로 계산 범위를 3,000mm까지 확장했습니다.
- 기존 100mm 구간 표 방식과 교차수량 × 1,000원 계산을 유지합니다.
