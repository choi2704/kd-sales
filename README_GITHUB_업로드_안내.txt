GitHub 배포 방법
1. 이 ZIP을 먼저 압축 해제하세요.
2. GitHub 저장소(kd-sales 등)의 최상위 폴더에 압축 푼 모든 파일/폴더를 업로드하세요.
   ZIP 파일 그대로 업로드하지 마세요.
   index.html, awning-calculator.html, data/ 폴더가 같은 루트에 있어야 합니다.
3. 기존 파일은 동일한 이름으로 교체하고 Commit changes 클릭.
4. GitHub 저장소 Settings > Pages 에서 Branch / (root) 배포 설정 확인.
5. 업데이트가 반영되지 않으면 웹브라우저 강력 새로고침(Ctrl+Shift+R) 해보세요.
